# Velvet Steps 👠

Velvet Steps is a modern, luxurious e-commerce landing page designed for an exclusive footwear boutique. Built with the latest frontend technologies, it offers a seamless, responsive, and aesthetically pleasing shopping experience. 

The design emphasizes high-quality product imagery, elegant typography, and smooth micro-animations to create a premium feel.

## 🌟 Features

- **Modern UI/UX**: A clean, luxury-focused design featuring the `Playfair Display` font for headings.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewing. Custom grid layouts ensure products are displayed perfectly on all screen sizes.
- **Product Showcases**: Engaging product grid components ("Step into Style") and highlighted customer favorites ("Customer Favorites") using dynamic hover scaling effects.
- **Component-Based Architecture**: Built with modular React components for easy maintenance and scaling.
- **High-Performance**: Powered by Vite for lightning-fast hot module replacement (HMR) and optimized production builds.

## 🛠️ Tech Stack

This project leverages exceptional modern web development tools:

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Linting**: ESLint with React support

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js installed on your machine.
- npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo (if applicable) or navigate to the project directory:
   ```sh
   cd "Velvet Steps"
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## 📂 Project Structure

- `src/components/`: Reusable UI components (e.g., `Products.jsx`, `FavSection.jsx`).
- `src/assets/`: Static assets such as images and icons.
- `src/App.jsx`: The main application orchestrator.
- `src/index.css`: Global styles and Tailwind directives.

## 🎨 Design Notes

The application uses a carefully selected color palette:
- **Primary Accent**: `#8B4302` (Earthy Brown)
- **Backgrounds**: Crisp whites `#FFFFFF` and off-whites `#FFFBF9` or `#E7E4E4`
- **Typography**: `Merriweather` for body text and `Playfair Display` for sophisticated headings.
