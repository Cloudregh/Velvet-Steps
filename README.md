## 👠 About

Velvet Steps is a modern, luxurious e-commerce landing page designed for an exclusive footwear boutique. It's built around high-quality product imagery, elegant typography, and smooth micro-animations, the kind of details that make a shopping experience feel premium rather than just functional.

## ✨ Features

- **Modern UI/UX** — A clean, luxury-focused design built around the Playfair Display typeface for headings
- **Responsive Layout** — Fully optimized for mobile, tablet, and desktop with custom grid layouts
- **Product Showcases** — Engaging product grids and a "Customer Favorites" section with dynamic hover scaling
- **Component-Based Architecture** — Modular React components for easy maintenance and scaling
- **High Performance** — Powered by Vite for lightning-fast HMR and optimized production builds

## 🛠️ Built With

- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React

## 🚀 Getting Started

**Prerequisites:** Node.js and npm

```bash
# Navigate to the project directory
cd "Velvet Steps"

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 📂 Project Structure

```
src/
├── components/   # Reusable UI components (Products.jsx, FavSection.jsx)
├── assets/       # Static assets (images, icons)
├── App.jsx       # Main application orchestrator
└── index.css     # Global styles and Tailwind directives
```
